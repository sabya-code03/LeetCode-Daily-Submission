# LeetCode Daily Submission 🧩

A daily log of my LeetCode problem-solving journey, with solutions written in **C++**.

This repository serves as both a personal archive and a way to stay consistent with practicing data structures and algorithms — one problem at a time.

## 📌 About

- Solutions are added regularly as I solve LeetCode problems.
- Each solution is written in C++, focusing on clean and readable code.
- The goal is to build consistency, sharpen problem-solving skills, and prepare for technical interviews.

## 📂 Repository Structure

Each problem is organized in its own folder or file, typically named after the problem number and/or title, for example:

```
LeetCode-Daily-Submission/
├── 0001-Two-Sum/
│   └── solution.cpp
├── 0217-Contains-Duplicate/
│   └── solution.cpp
├── 0242-Valid-Anagram/
│   └── solution.cpp
└── README.md
```

> Note: Folder/file naming may evolve over time as more problems are added.
